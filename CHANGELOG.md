# Architecture kit changes

## 2026-09-13

- Made architecture/interface names stable and independent of project generations.
- Separated portable host services from the optional Linux/NixOS reference.
- Defined 51 precise tool operations with 13 initially visible, corrected effect
  metadata, and added bounded input/result schemas with offline references.
- Added guarded outcome reconciliation and configurable controller budgets.
- Added a primary-source research register, Linux selection guide and measured
  synthetic retrieval experiment without claiming universal speed/token gains.
- Added local integrity/semantic checks, standards-validator entry points,
  acceptance fixtures and reproducible manifest refresh.
- Closed cursor input/output gaps, required successful-build artifacts, made
  settled process exits exclusive, and added all ten result examples plus
  cross-field count, byte-window, anchor and table regressions.

- Added an optional exact-revision Linux Flake, review-gated Direnv entry point,
  Just recipes, validator-environment smoke check and host setup guide.
- Extended manifest kinds for development files and excluded local .direnv state.

- Added the host-free agent-starter profile and resolved single-agent config.
- Defined typed runtime/adapter/grant/receipt/resume payloads and concrete
  context, accounting, external-service and persistence policies.
- Decoupled basic observation from optional coordination; retained the stronger
  multi-adapter portability gate as a separate milestone.
- Added nine synthetic event-replay scenarios, schema acceptance cases and
  independent negatives for authority, budgets, waiting and recovery.
- Added STARTER.md and Just recipes; no production runtime or host/HM changes.
